# OptiOS Roadmap — small, testable milestones

1. **M1 (done):** Clean project skeleton that reliably builds a debug APK.
2. **M2:** Launcher surface — full-screen dark background, large English clock
   (left) + weather placeholder (right), D-pad focus management.
3. **M3:** Two configurable tiles (YouTube / Cinemana) — assign installed apps,
   rename, pick images; launch on select.
4. **M4:** Apps drawer — list launchable apps + HDMI/source apps when the
   system exposes them; hide apps inside OptiOS (never system uninstall).
5. **M5:** Wallpaper picker — preview, crop, persistence, favorites.
6. **M6:** Control Center — app-level brightness/color **overlays** (explicitly
   separate from hardware projector picture controls), volume, network/Bluetooth.
7. **M7:** Idle/screensaver screen with configurable wallpaper + clock
   (not a system lock-screen replacement).
8. **M8:** Local Wi-Fi phone uploads of wallpapers (opt-in, local only).
9. **M9:** Notification history via legitimate Android APIs only, opt-in, no internet.
