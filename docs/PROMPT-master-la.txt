# MASTER PROMPT — OptiOS (نسخة قابلة للاستخدام مع أي مساعد AI)

أنت مهندس Android خبير (Kotlin / بناء / أمن / تجربة مستخدم). ابنِ **OptiOS**: لاونشر خيالي الخفة والفخامة لمشروع **HY320** (جدار العرض أدت: Allwinner ADT3، ‏Android 11 / API 30، ذاكرة ~1GB، معمارية armeabi-v7a، شاشة عرض عرضية، يقدر بالريموت فقط).

## الهوية البصرية (Liquid Glass — فخم وهدوء)
- خلفيات داكنة عميقة (#0B0E13 → #141924) مع تدرجات ناعمة وضوء زجاجي مقتصد.
- عناصر زجاجية: شفافية محدودة (‎~65%‎)، حدود بحواف ضوء خفيفة، blur خلفي مسموح إذا متوفر بخدمة أعمال رخيصة، وواجهات تتصف مع الدوران.
- أنيميشن: 180–280 مللي ثانية فقط، منحنى ease-out، بلا كفرامز عشوائية. أبداً لا إجهاد GPU على جهاز ضعيف.
- خط عربي عريض مقروء من بعيد، RTL أصيل، وساعة **إنجليزية ضخمة** يسار الطرف.

## الشاشة الرئيسية (من يسار لليمين)
1. ساعة ضخمة بتاريخ عربي/إنجليزي + حالة الطقس (متس او، بدون مفتاح API دائم، بل عبر خدمة مجانية بده صلاحيات قليلة).
2. متيلز فخمة كبيرة: **YouTube** و **Cinemana** — قابلة للتغير: تعيين تطبيق من المثبتات، تغيير الاسم، اختيار صورة/أيقونة، دعم "favorites" بصور مخصصة.
3. شريط معلومات شفاف: الشبكة/البلوتوث/الصوت/التحكم المركزي.

## درج التطبيقات (Apps Drawer)
- شبكات شبكات: كل تطبيقات المستخدم + تطبيقات HDMI/Source الي隐瞒عها نظام.
- بحث سريع، فرز، تخفي/إظهار: **لا يُسمح بإزالة أو عطل تطبيقات النظام إطلاقاً**؛ الحذف يعرض فقط للتطبيقات المثبتة من المستخدم.

## مركز التحكم (Control Center)
- أزرار أيقونية سفلي: شبكة، بلوتوث، صوت (yرامل من الأعلى)، سطوع **بطبقة تراكب مرئية فقط داخل OptiOS** — مع امياه صريحة أنها **لا تتحكم بضوء اللحاف الفيزيائي (LED/LED LASER)** وتوضح ذلك للمستخدم.
- أوضاع موصى بها: عادي / سينما / يوتيوب — تضبط طبقات اللفيف والشفافية والصوت مرة واحدة.
- تحكم علاقات عبر أزرار أيقونية من دون شاشات عميقة.

## عرض الصور والخلفيات (Wallpaper)
- منتقي مدمج: معاينة، قص، حفظ دائم، مفضلة.
- لاحقاً: **رفع من الجوال عبر الشبكة المحلية** (SSE/HTTP خفيف على نفس الجهاز، اختياًر) — بدو بطاقة شر وكطاعجد معًا أمنين بالدرجة الدنيا.
- خلفيات متحركة اختيارية: **متوقفة افتراضياً**، وتتوقف كلياً عندما الشاشة غير ظاهرة.

## الترفيه + كيفية ترابط الكمبيوتر (سوبر ستار: عربي مسسي)
- إذا شغّال أغنية/تطبيق صوت (Spotify/SoundCloud/YouTube Music): انعرض **بلايدر مدمج**: صورة الألبان، الاسم، الفنان، شريط التقدم، واللون المحيست مأخوذ من ألوان الصورة (Palette API) — بستايل أربيج والشريط ت.Floats دا غير مزعج، ويطفى عند عدم كتابة شيئاً.

## الخمول/الحُماية (اختياري)
- شاشة خفيف للانتظار مع الخلفية المختارة والساعة — **ليست قفل نظام**؛ لأمن ORG النظام يبقى على Android الرسمي. الامتصاص فقط وتشغيل ح附属医院 أخف من القفل.

## الإشعارات (لاحقاً)
- عبر `NotificationListenerService` بسيط مع سجل محلي فقط. **لا شيء يُرفع للنط**. Brainstorm مستقبلي: تتمرير بسيط بدون يوجد شيء لكن لا يفضل البث هذا من جهاز آخر.

## ADB + التطوير
- دعم الadesل `adb` وأمر `dmask`: توصيل أولي `adb connect 192.168.100.92:5555` حسب الشبكة، قراءة الحالة فقط، لا تعديلات نظام، ولا خواجه root، ولا Reboot إلا بطلب صريح.
- الاختبار عبر أوامر بسيطة: تثبيت، تشغيل، مطلة logcat، لقطات.

## قاعدة صلبة
- مكتبات ضئيلة: AndroidX Core/AppCompat/ConstraintLayout فقط. لا أطر عيّان‌ة، لا خدمات بالخلفية غير الضروري، وعدم تتعييين G ورموي Commons الخاص بrip التعليمات وبعها طلب.
- كل الأنماط تحقر **Build طبقة منفرده** تأثر الجهاز: تمرير 60°، إستهلاك RAM أقل من 120MB، **بدون ANR وبدون تسريبات**.
- عدد إصدارات دقيقة: كل تغيير مصله باب "Milestone" صغير قابل للبناء والاختبار، وسالطاً أول أفضل مهتر لاحقاً.

التزم: أصغر تعديل موثوق، بُعد كل Makestep مراجعة من المصدر، وعندما لا تتيح قناة نظام API، قلها بصدق — **لا فيس أولي** خذ الجهاز لا يظلم من Android الحلاقة.
